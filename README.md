# Democracy Alpha Workbench

Democracy Alpha Question Workbench v2.2 — Opposition International analytical tool for multi-channel opposition assessment.

## Quick start

- Clone the repo:

  git clone https://github.com/owenlippert-stack/democracy-alpha-workbench.git
  cd democracy-alpha-workbench

- Create and activate a virtual environment:

  python -m venv .venv
  source .venv/bin/activate  # macOS / Linux
  .\.venv\Scripts\activate   # Windows (PowerShell)

- Install dependencies (when available):

  pip install -r requirements.txt

- Run the app or tests (see docs or examples)
